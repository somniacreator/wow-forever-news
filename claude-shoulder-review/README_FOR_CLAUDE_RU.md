# Проверка реального размера наплечников для WoW Forever

## Цель
На модели нежити наплечники уже оказываются у плечевых костей, но на скриншоте выглядят крупнее игрового размера. Нужна корректная привязка и размер, соответствующий WoW, без подбора коэффициента на глаз.

## Что приложено
- `data/scourgefemale_hd.glb` — модель нежити из wow.export.
- `data/shoulder_armor_skybornec60_d_01_l_7751193.glb` и `..._r.glb` — отдельно экспортированные модели левого и правого наплечников.
- `src/wf-armory-import.mjs` — код объединения мешей GLB и привязки к костям `bone_ShoulderL/R`.
- `src/wf-armory-shoulder-fix.js` — восстановление отцепившихся при экспорте моделей наплечников.
- `src/wf-wow-model-viewer.js` — просмотрщик модели.
- `tests/armory-glb-shoulders.test.mjs` — проверки формата GLB и привязки.
- `reference/shoulders-too-large.png` — результат теста в приложении.

## Важные ограничения
Не задавай произвольный коэффициент масштаба. Сначала установи, какому предмету/DisplayID соответствуют приложенные GLB и как wow.export кодирует их исходный масштаб и трансформацию. Сравни с моделью того же персонажа, экспортированной из игры с этим предметом надетым, либо с подтверждённой трансформацией этого DisplayID. Затем исправь перенос трансформации так, чтобы наплечники сохраняли игровой размер и правильно следовали костям плеч. Не менять Release.

Если для точного сравнения в приложениях недостаточно исходных данных, перечисли конкретно, что нужно выгрузить из wow.export: GLB той же нежити с надетым именно этим предметом и/или исходный GLB предмета с его иерархией/скелетом. Не заменяй отсутствующие данные оценкой на глаз.
