WoW Forever Armory Exporter — Draft 0.1.11

Назначение
Собирает сведения о персонаже и экипированных предметах в SavedVariables, чтобы проверить передачу данных из клиента WoW Forever в будущую 3D-Оружейную.

Аддон НЕ извлекает сетку, текстуры или готовую 3D-модель из файлов игры и НЕ отправляет данные в интернет. Он сохраняет имя, сервер, уровень, расу, класс, пол (если API клиента его отдаёт), фракцию, ID/ссылку/иконку вещей и сведения о сборке клиента.

Новое в 0.1.11 — кнопка у мини-карты появляется всегда: она создаётся при входе раньше сбора данных, поэтому ошибка в трансмоге, талантах или характеристиках больше не может её убрать. Если какая-то часть не собралась, аддон пишет в чат «ошибка при сборе данных — …», а остальная выгрузка работает. Команда /wfa button создаёт кнопку, если её нет, и скрывает/показывает её.

Новое в 0.1.10 — золото: в JSON добавлено поле money — деньги персонажа в меди, как их отдаёт GetMoney() (1 золотой = 10 000 меди). Оружейная показывает их в полосе внизу окна, как в сумке.

Новое в 0.1.9 — окно в стиле Оружейной:
• окно выгрузки оформлено как окно персонажа в Оружейной: коричневая панель в золотой рамке с тёплым светом сверху, круглый портрет персонажа с уровнем, золотое имя, класс (цветом класса), раса и сервер, тёмная область с текстом и красные кнопки;
• подсказка в окне ведёт к новому блоку Оружейной «Загрузить персонажа из игры».
Данные выгрузки не изменились.

Новое в 0.1.8 — таланты:
• в JSON появился блок talents: для каждого набора талантов (если в клиенте есть двойная специализация — для обоих) все ветки класса с названием, иконкой и числом вложенных очков, а в каждой ветке — каждый талант: название, иконка, ряд (tier), столбец (column), вложено (rank) и максимум (max_rank); плюс active_group — активный набор и unspent — нераспределённые очки;
• в чат после выгрузки выводится строка вида «Таланты: Колдовство 7 / Демонология 0 / Разрушение 5»;
• в ссылку для Telegram добавлено короткое распределение активного набора (например 52--5); прежние версии приложения это поле просто пропускают;
• данные берутся из API клиента (GetTalentTabInfo, GetTalentInfo и др.); если клиент WoW Forever какую-то функцию не отдаёт, поле просто отсутствует;
• списки (ветки, таланты) теперь записываются в JSON настоящими массивами, по порядку.
Для проверки нужен персонаж с распределёнными талантами (с 10 уровня).

Новое в 0.1.7 — трансмогрификация:
• для каждого надетого предмета аддон сохраняет облик трансмога: look_item_id — ID вещи, в которую трансмогрифицирован слот, или look_hidden = true, если облик скрыт;
• облик попадает и в JSON, и в ссылку для Telegram (slot.item.look или slot.item.x);
• в Оружейной модель надевает облик трансмога, а в слоте и карточке остаётся настоящая вещь с её характеристиками и припиской «Трансмогрифицировано в: …»;
• данные берутся из API клиента C_Transmog / C_TransmogCollection; если в клиенте их нет, предметы выгружаются без облика, как раньше.

Новое в 0.1.6 — ссылка для Telegram в том же окне:
• кнопка «Ссылка для Telegram» в окне (или Shift + левая кнопка мыши по кнопке у мини-карты, или /wfa link) показывает ссылку вида https://t.me/WoWForeverRUBot?startapp=WFA1_…;
• ссылку можно отправить в любой чат Telegram, хоть себе в «Избранное»; по нажатию откроется мини-приложение, Оружейная загрузит персонажа и сохранит его в «Мои персонажи»;
• в ссылке раса, пол, класс, уровень, имя, сервер и ID надетых предметов (Telegram пропускает не больше 512 символов); характеристики, качество и иконки передаёт только JSON;
• кнопка «JSON для сайта» возвращает окно к полному JSON;
• в JSON добавлен character.race_id — номер расы из клиента.
Этот аддон заменяет старый WFArmory: у обоих команда /wfa, поэтому WFArmory лучше отключить.

Новое в 0.1.5 — кнопка у мини-карты:
• левая кнопка мыши — выгрузить персонажа: открывается окно с готовым JSON, текст уже выделен; нажмите Ctrl+C и вставьте его в Оружейной в поле «Дополнительно: импорт JSON профиля» → «Показать данные из JSON». Искать файл в WTF и вводить /reload больше не нужно;
• правая кнопка мыши — краткая сводка в чат;
• кнопку можно перетащить по краю мини-карты, положение запоминается;
• в окне есть кнопка «Сохранить файл» (/reload), если нужен и файл SavedVariables.
Символ «|» из ссылок на предметы записывается в JSON как \u007c, чтобы окно игры не превращало ссылки в цветной текст; Оружейная читает его как обычный «|».

Новое в 0.1.4 — снимок больше не затирается пустыми данными при выходе из игры или /reload: аддон обновляет его, только когда персонаж полностью загружен.

Новое в 0.1.3 — качество предмета берётся из ссылки, если клиент ещё не загрузил данные предмета.

Новое в 0.1.2 — блок stats с характеристиками персонажа, как их отдаёт клиент:
• здоровье и запас маны/ярости/энергии;
• сила, ловкость, выносливость, интеллект, дух (база, итог, бонус, штраф);
• броня;
• ближний бой: сила атаки, шанс крита, бонус меткости, урон и скорость оружия;
• дальний бой: сила атаки, шанс крита, урон и скорость;
• заклинания: шанс крита и бонус к урону по школам, бонус к исцелению, меткость, восполнение маны;
• защита: уклонение, парирование, блок;
• сопротивления: светлая магия, огонь, природа, лёд, тьма, тайная магия.
Если клиент не поддерживает какую-то функцию, поле просто отсутствует — аддон ничего не досчитывает сам. Характеристики обновляются при входе, смене экипировки и по команде /wfa export.

Установка
1. Распакуйте папку WFA_Armory_Exporter в папку игры: Interface\AddOns\WFA_Armory_Exporter\
2. Полностью перезапустите игру и включите WoW Forever Armory Exporter в списке аддонов. В манифесте указан Interface: 16001 — номер интерфейса клиента WoW Forever beta 1.60.x.
3. Войдите персонажем. У мини-карты появится круглая кнопка с иконкой кольчуги.
4. Нажмите её левой кнопкой мыши. В чате появится сводка (имя, раса, класс, число предметов, build клиента, основные характеристики), а на экране — окно с JSON.
5. Нажмите Ctrl+C, откройте Оружейную, раскройте «Дополнительно: импорт JSON профиля», вставьте текст (Ctrl+V) и нажмите «Показать данные из JSON».
Файл SavedVariables по-прежнему пишется при /reload или выходе из игры: WTF\Account\<учётная запись>\SavedVariables\WFA_Armory_Exporter.lua.

Команды
/wfa или /wfa export — то же, что левая кнопка у мини-карты: снимок и окно с JSON.
/wfa link — снимок и окно со ссылкой для Telegram.
/wfa show — показать сводку последнего снимка.
/wfa button — скрыть или снова показать кнопку у мини-карты.

Что проверяем
1. Загружается ли аддон в клиенте WoW Forever.
2. Верно ли определяются race/class/gender и build клиента.
3. Совпадают ли ID предметов в файле со слотами экипировки на экране персонажа.

После проверки добавим поддержку формата аддона в импорт Оружейной. Затем отдельно подключим источник 3D-моделей и сопоставление предметов с их display ID. Это остаётся Draft и не меняет опубликованное приложение.
